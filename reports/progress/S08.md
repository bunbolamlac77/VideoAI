| `afterMaterializedBeforeVerified` | `MATERIALIZED` | Temp file chưa verify | Thu hồi attempt cũ, cách ly file tạm `.quarantined` | 🟢 PASS |
| `afterVerifiedBeforeRename` | `VERIFIED` | Temp file đã băm SHA-256, chưa rename | Thu hồi attempt cũ, cách ly file tạm `.quarantined` | 🟢 PASS |
