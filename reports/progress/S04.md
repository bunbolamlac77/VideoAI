## 2. Các Hạng Mục Sửa Đổi & Nghiệm Thu Kỹ Thuật

1. **Swift DataContracts Codable snake_case & ISO-8601:**
   - Cập nhật `packages/AIVideoCore/Sources/Models/DataContracts.swift` với explicit `CodingKeys` (snake_case) cho `TimeRange`, `ClaimRecord`, và `ArtifactPublicationRecord`.
   - Triển khai custom `init(from decoder:)` và `encode(to encoder:)` định dạng `Date` chuẩn ISO-8601 strings (`yyyy-MM-dd'T'HH:mm:ss'Z'`), hỗ trợ cả fractional seconds khi parse dữ liệu từ Python.
   - Bổ sung bộ golden tests hai chiều Swift <-> Python (`contracts/fixtures/golden_claim_*.json`, `golden_artifact_*.json`): Swift đọc và decode fixture Python, Python đọc và decode fixture Swift, round-trip 100% parity.

2. **SQLite Claims Table — Hỗ Trợ Nhiều Revision Cùng Logical `claim_id`:**
   - Sửa `contracts/migrations/001_initial_g1_schema.sql`: tách `revision_id TEXT PRIMARY KEY NOT NULL` (mỗi bản ghi là snapshot bất biến) và `claim_id TEXT NOT NULL` (định danh logic xuyên suốt các revision).
   - Thêm index `idx_claims_claim_id ON claims(claim_id)`.
   - Đảm bảo lịch sử append-only bất biến, cho phép lưu trữ trọn vẹn tiến trình revision 1 (unreviewed) -> revision 2 (confirmed) mà không bị xung đột khóa chính.

3. **Kiểm Thử SQLite WAL Thực Tế Trên Disk File Tạm:**
   - Thay thế test `:memory:` bằng `tempfile.TemporaryDirectory()` trên file database thật `test_g1_wal_store.db`.
   - Xác nhận `PRAGMA journal_mode;` trả về chính xác `'wal'`.
   - Xác nhận `PRAGMA foreign_keys = ON;` từ chối các bản ghi vi phạm khóa ngoại.
   - Xác nhận chèn và truy vấn thành công 2 revision khác nhau của cùng 1 `claim_id`.

4. **Tăng Ràng Buộc JSON-RPC Envelope — Từ Chối Message Chỉ Có `jsonrpc`:**
   - Trong `contracts/schemas/rpc_envelope_schema.json`: thêm `oneOf` bắt buộc message phải là 1 trong 4 loại hợp lệ: Request (có `id` + `method`), Notification (có `method`, không có `id`), Success Response (có `id` + `result`), hoặc Error Response (có `id` + `error`). Message chỉ có `{"jsonrpc": "2.0"}` hoặc chỉ có `id` bị schema từ chối.
   - Trong Swift `DomainModels.swift` và `WorkerClient.swift`: cập nhật `JSONRPCResponseEnvelope` để kiểm tra sự tồn tại của `method`, `result`, `error`. Từ chối ngay lập tức với `WorkerError.framingError` nếu frame thiếu cả ba hoặc chỉ có `id` mà thiếu `result`/`error`.
   - Trong Python Worker `main.py` và `test_framing_resilience.py`: kiểm tra và bắt lỗi `-32600 Invalid Request` khi nhận message bare `{"jsonrpc": "2.0"}`.

5. **Xóa Dòng S04 Trùng Lặp Trong `PROGRESS_TRACKER.md`:**
