## 2. Tóm Tắt Mục Tiêu & Yêu Cầu Kỹ Thuật

- **Đầu vào (Inputs):** Nghiệm thu hoàn tất Gate G0 (Platform Spike PASS 100%).
- **Đầu ra kỳ vọng (Expected Outputs):**
  - Định nghĩa JSON Schema thực thi cho Claims, Artifact Publications, RPC Envelope.
  - Mã nguồn DTO và State Machine song ngữ đồng bộ: Swift Core (`DataContracts.swift`) và Python Worker (`data_contracts.py`).
  - Bản di chuyển SQLite WAL khởi đầu: `contracts/migrations/001_initial_g1_schema.sql`.
  - Bộ kiểm thử tự động xác thực các bất biến trạng thái: không tự ý đổi boolean, không biến `user` fact thành `observed`, không nhảy cóc trạng thái artifact từ `PREPARED` lên `COMMITTED`.
- **Ràng buộc cốt lõi (Core Invariants):**
  - **5 Trục bằng chứng độc lập:** `origin`, `epistemic_status`, `review_status`, `support_status`, `allowed_use`.
  - **Chu trình công bố artifact 4 bước:** `PREPARED` → `MATERIALIZED` → `VERIFIED` → `COMMITTED`.
  - **Fencing token:** Quản lý attempt tiến trình con, chống ghi đè dữ liệu từ attempt trễ.
  - **SQLite WAL:** Single-writer actor `ProjectStore`, transaction ngắn, foreign keys enforced.
